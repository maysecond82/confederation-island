# L'île de la Confédération

Un jeu d'histoire en pixel art, en français : naviguez de 1861 à 1999 et décidez comment le Canada a été bâti.

**Jouer :** https://maysecond82.github.io/confederation-island/

Tout le jeu tient dans un seul fichier, `index.html`. Les réponses de l'IA, le multijoueur et le classement ne fonctionnent que dans la version publiée sur claude.ai ; ici, le reste du jeu fonctionne normalement.
